# Oasis Infobyte Cyber Security Internship

Welcome to my cybersecurity internship repository.

This repository contains the practical cybersecurity tasks completed as part of the **Oasis Infobyte Cyber Security Internship**. The projects focus on network security, system security, web application security, vulnerability assessment, and network traffic analysis.

The work was performed in controlled environments for educational and cybersecurity learning purposes.

---

## Internship Tasks

The following tasks have been completed and documented in this repository:

- **Task 1 – Basic Network Scanning with Nmap**
- **Task 2 – Basic Firewall Configuration with UFW**
- **Task 3 – SQL Injection on DVWA**
- **Task 7 – Vulnerability Scanning with Nikto**
- **Task 8 – Network Traffic Analysis with Wireshark**

---

## Task 1 – Basic Network Scanning with Nmap

The first task focused on performing basic network reconnaissance using Nmap in a controlled environment.

### Activities Performed

- TCP port scanning
- Service version detection
- Operating system detection
- Aggressive scanning
- Port-specific scanning
- Analysis of discovered services

The results were documented and analyzed to understand the security implications of exposed network services.

---

## Task 2 – Basic Firewall Configuration with UFW

The second task focused on configuring and testing a firewall using UFW (Uncomplicated Firewall).

### Activities Performed

- Installed and configured UFW
- Allowed SSH traffic
- Blocked HTTP traffic
- Added custom firewall rules
- Verified firewall configuration
- Documented the testing methodology

The task provided practical experience with host-based firewall configuration and basic network access control.

---

## Task 3 – SQL Injection on DVWA

The third task focused on understanding and demonstrating SQL Injection vulnerabilities using **Damn Vulnerable Web Application (DVWA)** in a controlled local environment.

### Activities Performed

- Configured DVWA on a local server
- Tested SQL Injection under Low Security
- Demonstrated multiple SQL Injection payloads
- Retrieved database information through the vulnerable application
- Analyzed the security impact of SQL Injection
- Documented mitigation techniques and security best practices

The task provided practical experience in identifying web application vulnerabilities and understanding the importance of secure input validation and database query handling.

---

## Task 7 – Vulnerability Scanning with Nikto

The seventh task focused on automated web server vulnerability scanning using **Nikto** against a locally hosted DVWA environment.

### Activities Performed

- Configured a local DVWA testing environment
- Performed vulnerability scanning using Nikto
- Identified potentially insecure files and server configurations
- Saved the Nikto scan results
- Analyzed the reported security findings
- Documented appropriate remediation measures

The scan results and vulnerability analysis are included in the dedicated Task 7 project directory.

## Task 8 – Network Traffic Analysis with Wireshark

The eighth task focused on capturing and analyzing network traffic using **Wireshark**.

### Activities Performed

- Captured live network traffic from the Wi-Fi interface
- Analyzed HTTP traffic using Wireshark display filters
- Identified DNS queries and responses
- Analyzed TCP communication
- Identified a TCP three-way handshake using SYN, SYN-ACK, and ACK
- Inspected an unencrypted HTTP GET request
- Analyzed the protocol hierarchy of the captured traffic
- Documented security observations and recommendations

The complete packet capture and supporting screenshots are included in the dedicated Task 8 project directory.
