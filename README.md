# Oasis Infobyte Cyber Security Internship

Welcome to my cybersecurity internship repository. This repository contains the practical tasks I completed as part of the **Oasis Infobyte Cyber Security Internship**, focusing on networking, system security, and web application security.

## Repository Structure

### Task 1 – Basic Network Scanning with Nmap
- Performed TCP port scanning
- Service version detection
- Operating system detection
- Aggressive scanning
- Port-specific scanning
- Security analysis of discovered services

### Task 2 – Basic Firewall Configuration with UFW
- Installed and configured UFW
- Allowed SSH traffic
- Blocked HTTP traffic
- Added custom firewall rules
- Verified firewall configuration
- Documented testing methodology

### Task 3 – SQL Injection on DVWA
- Configured DVWA on a local server
- Demonstrated SQL Injection on Low Security
- Tested multiple SQL Injection payloads
- Retrieved sensitive data from the database
- Documented mitigation techniques and best practices

## Technologies Used

- Kali Linux
- Nmap
- UFW (Uncomplicated Firewall)
- Apache2
- MariaDB
- DVWA (Damn Vulnerable Web Application)
- Git
- GitHub

## Ethical Disclaimer

All experiments were conducted in a controlled local environment for educational purposes only. No unauthorized systems or third-party networks were targeted.
